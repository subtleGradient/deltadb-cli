# Success / anti-success

1. Human guide provides read-first native and SQLite routes and safe sandbox practice.
2. Every route names its selector and runtime dependency.
3. Skill instructions and references are self-contained and linked locally.
4. Preview rules explicitly distinguish immediate `init` creation and native
   thread-deletion preview from local recording previews.
5. Native parser/mocked behavior never becomes end-to-end/full-CRUD proof.
6. Unsupported message deletion cannot be substituted with thread deletion.
7. Source is versioned/backed up; generated global copies match source.
8. Packaging checks and synthetic CLI tests pass. Casebook desk review is labeled
   as review, not executable model behavior testing.

Anti-done: docs only in chat, hardcoded skill checkout dependencies, broad private
transcript collection, automatic native writes, or a fake claim of complete CRUD.
