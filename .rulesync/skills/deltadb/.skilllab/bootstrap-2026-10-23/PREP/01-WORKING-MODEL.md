# Working model / dimensional slices

| Slice | First side | Other side | Example |
| --- | --- | --- | --- |
| Runtime | Native installed app/account | Standalone SQLite | threads vs tables |
| Effect | Read/preview | Applied mutation | typed record preview vs --apply |
| Evidence | Shape/parser acceptance | Persistence/projection proof | current native text vs unverified storage |
| Scope | One producer/message range | Whole private corpus | status and 1-20 vs bulk dump |
| Ownership | One dedicated writer | Shared identity contention | own external ID vs another integration |

These are distinctions, not ranked moral categories. The guide must expose each
before an agent chooses an execution route.
